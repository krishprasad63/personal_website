# Krish Prasad Personal Website

A static, dependency-free first version of an interactive ECE portfolio.

## Concept

Krish Lab: Live Digital Systems Portfolio. The site is designed around real engineering behavior: pipeline flow, timing diagrams, serial protocols, RTL modules, and leadership in technical communities.

## Local Preview

From this folder, run:

```powershell
python -m http.server 5173
```

Then open `http://localhost:5173`.
